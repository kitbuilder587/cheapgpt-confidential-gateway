# Security

This is a pre-deployment implementation. It has not received an independent security audit or a live Phala acceptance test. Please assess the [trust model](docs/security.md) before using sensitive data.

Report vulnerabilities through this repository's **Security → Report a vulnerability** feature. If it is unavailable, contact a repository maintainer privately. Do not include credentials, plaintext requests or private routing configuration in issues, logs or public test fixtures.

Only the current `main` branch is maintained. Changes to the measured image or deployment require renewed client approval; updates are never silently trusted by the SDK.
